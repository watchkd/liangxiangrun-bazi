# 资料库补录：本批新登记的梁湘润底本

> 起因：此前技能包只用了 5 本已 OCR 的书（`_语料库/LXR-*`），而 `D:\梁湘润` 下其实还有

---

## 1. 为什么这批比 OCR 的更可靠

| | OCR 本 | 本批（文字层直抽） |
|---|---|---|
| 字形错误 | 有，需逐字校（如 己/乙/已 混） | 无 OCR 环节 |
| 风险点 | 识别错误 | 简体转写者改字、漏行 |
| 证据等级 | 图版 E1（可回图） | 电子文本 E3（**不可回图**） |
| 用途 | 定本、命例回图 | 检索、比对、找条文出处 |

**两者不可互相替代。** 本批文字只能作 E3；凡涉及命例四柱、具体字句定本，仍须回图版。

## 4. 抽文方法的局限（必须知道）

1. **文字层 ≠ 已校。** 这批 PDF 多为网友简体转写，存在改字、漏行、表格丢失。本批只做了抽取，**未做任何校对**。
2. **表格丢失。** `pymupdf.get_text()` 不还原表格结构；《余氏用神辞渊》的「日主／月／用神／忌神」四列表在抽文中被压成单列段落，无法直接当表用。
3. **同书多本并存。** #4/#5、#2/#7、#17/#18/#19 是同书异本，已按正文 sha256 去重到不同条目，比对时须先确认用哪一本。
4. **未抽文的书更多。** `D:\梁湘润` 下 121 个 PDF 里，约 80 本无文字层（行卯版扫描本为主），仍在等 OCR。
5. **非梁湘润著作另计。** 三命通会、廖冀亨《子平四言集腋》、廖平《命理支中藏干例》、刁吉祥《命理玄机》本批未登记，需另立「参考古籍」类。

## 5. 怎么用

```bash
# 全书检索（示例：找「羊刃驾杀」在哪几本出现）
cd /d/梁湘润/_语料库/LXR-TEXT
grep -l "羊刃驾杀" *.txt

# 看某本书的规模与校验值
python -c "import csv,io;[print(r['字数'],r['页数'],r['书名']) for r in csv.DictReader(io.open('_manifest.csv',encoding='utf-8-sig'))]"
```

引用格式：

- 引条文 → 「梁湘润《余氏用神辞渊》（简体转录本，E3，第 N 页）」＋ 若涉定本另注「须回行卯版图版」
- 引梁氏亲述版本 → 可标 E1（目录/卷首图版），但须注明「OCR 转写，个别字待核」
