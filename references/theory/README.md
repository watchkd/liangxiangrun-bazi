## 入此目录的铁规矩

1. **A 包内容一律 E5 整理者推论**，`deterministic_use` 最高「条件允许」，**永不给「允许」**，不得挂 E1–E4。
2. 每条须写明：编号（`T-A-*`）、断语、条件、**边界**、出处节号、待核标记。挂得上已入库 `rule_id` 的必须挂。
3. **不得以本目录内容补写梁氏原文、页码、出处。**
4. 本目录内容可进「讲解」与「线索」，**断语仍以 `data/rules.csv` 与 `data/tables.csv` 为准**；两者冲突时以入库规则为准。
5. `T-A-*` **不入 `data/rules.csv`**，不参与 `analyze.py` 自动检索——避免 E5 内容混入 E1–E4 的检索池。
