## 一、总则

### T-A-SS-001 神煞本身无吉凶

- **断**：神煞是一种现象，不是判决。桃花可身败名裂，也可人财两得；关键在**神煞与日主的生克关系**：

| 关系 | 取象 |
|---|---|
| 日主生神煞 | 自己主动 |
| 神煞生日主 | 别人主动来帮 |
| 日主克神煞 | 自己能掌控 |
| 神煞克日主 | 被控制（最忌大耗克身、驿马克身） |

- **出处**：A 包 §5 核心原则｜E5｜待回原书升核
- **与 B 的接口**：此即 `R-MF-044`～`046`「不作大吉大凶论」的同一条原则的不同说法；**两说并存，不合并**。
- **硬规矩**：`DECISIONS.md` C-13——命书只写「见某支／不见某支」＋与日主的生克，**不判吉凶**。

### T-A-SS-002 有效性分级

- **断**（《诀法今论》）：
  - 完全有效：桃花、驿马、华盖、咸池、天乙贵人
  - 部分有效：血刃、亡神、劫煞
  - 几乎无效：天德、月德（仅作辅助）
- **冲突提示**：此说与 B 的 `JS-SS-02`（月支查天月德，E1 已核）**不冲突**——起法仍依原表，只是「断语权重」低。报告中可写「见月德」，但不得据月德断吉凶。
- **出处**：A 包 §10｜E5｜待回原书升核

### T-A-SS-003 神煞可合（行卯修正）

- **断**：孤辰、寡宿可与天乙贵人、桃花、驿马相合——传统谓「孤辰寡宿不可合」，梁氏改之。
- **出处**：A 包 §10「神煞合论」｜E5｜待回原书升核
- **边界**：相合之后如何取象，A 包未给细则；**只可写「二煞同柱／同宫」，不得自行推吉凶**。

## 二、天月德

### T-A-SS-010 天月德的取法原理

- **断**：天月德按月令取，分三路：
  - 辰戌丑未月 → 阳干入库
  - 寅申巳亥月 → 阴干纳长生
  - 子午卯酉月 → 羊刃／绝位同宫（旺绝同在，能屈能伸）
- **出处**：A 包 §5｜E5｜待回原书升核

### T-A-SS-011 月德四格订正（C-02）

A 包原表在**子午卯酉**四个月把月德列留空，是误把「羊刃绝位」套到月德列。**本包采 B 值**：

| 月令 | 天德 | 月德 |
|---|---|---|
| 子 | 巳 | **壬** |
| 卯 | 申 | **甲** |
| 午 | 亥 | **丙** |
| 酉 | 寅 | **庚** |

- **依据**：`DECISIONS.md` C-02；`JS-SS-02`（E1 同书图版）
- **禁止**：不得再引 A 包原表之空格，不得据「月德缺」作任何断语。

### T-A-SS-012 天月德的作用

- **断**：天月德为「增福之神」。比劫破财而带天月德者，作「交际费」论——花钱有好处。
- **权重**：依 T-A-SS-002 属「几乎无效」，**只作辅助，不单独成断**。
- **出处**：A 包 §5｜E5｜待回原书升核

## 三、桃花

### T-A-SS-020 桃花的四种形态

| 形态 | 条件 | 取象 |
|---|---|---|
| 咸池桃花 | 申子辰见酉、寅午戌见卯、亥卯未见子、巳酉丑见午 | 基本形态 |
| 外桃花 | 子午卯酉日生于子午卯酉时 | 易外露 |
| 裸形桃花 | 外桃花带冲 | 最显 |
| 正官桃花 | 桃花与正官同柱 | 佳（深院之良人） |
| 七杀桃花 | 桃花与七杀同柱 | 不佳（走天涯） |

- **出处**：A 包 §5／§2｜E5｜待回原书升核
- **起法**：桃花依 `JS-SS-04` **以日支查**（D1），非通行本之「年支＋日支双查」。上表三合组为取象分类，与起法不矛盾。

### T-A-SS-021 桃花与日主的四种关系（举例）

- 甲戌日卯月：甲即桃花，日主＝桃花，平起平坐。
- 庚日见卯桃花：金克木，又乙庚合——**又克又合**，最缠夹。
- 戊日见卯桃花：桃花克我，一生麻烦。
- 壬日见卯桃花：日主生桃花，随时不放过机会。

- **出处**：A 包 §5／§10｜E5｜待回原书升核
- **用法**：**先算生克，再取象**——同是卯桃花，四种日主四种说法。

### T-A-SS-022 桃花带十神

- **断**：戊日见子桃花（子为癸水正财）→「桃花带财」，有感情也有交易；戊日见酉（辛金伤官）→「桃花带伤官」，烂桃花。
- **出处**：A 包 §10｜E5｜待回原书升核

## 五、天乙贵人

### T-A-SS-040 天乙起法

- **起法**：甲戊庚牛羊（丑未）、乙己鼠猴乡（子申）、丙丁猪鸡位（亥酉）、壬癸兔蛇藏（卯巳）、六辛逢马虎（午寅）。
- **口径**：依 `JS-SS-01`，**以日干查**（D1）。A 包作「年干＋日干双查」，降为对照说明。

- **用词**：原诀粗俚，只可作「贵人重叠反主奔波不定」。
- **出处**：A 包 §5／§10（《神煞探原》）｜E5｜待回原书升核

## 八、使用禁令

1. **起法不许自由选择**：一律 `JS-SS-*` 四表（D1）。来客问「我的软件显示有桃花」时，按 `DECISIONS.md` C-01 解释口径差异，**不改断语**。
2. **不判吉凶**：命书与报告只写「见／不见」＋生克（C-13）。凡「主凶」「大吉」一律改写。
3. **不叠加**：同一盘见数煞，不得逐煞加总成「大凶」——`R-MF-044`～`046` 三条都在削这种叠加。
4. **天月德不当断语用**：T-A-SS-002 已列「几乎无效」，只可记录。
