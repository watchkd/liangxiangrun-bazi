# 证据政策与状态门控

本文件是总装包的引用规则。所有 Agent、所有报告、所有 Skill 输出均受此约束。

## 1. 证据等级

| 代码 | 名称 | 说明 | 可作什么 |
|---|---|---|---|
| E1 | 同书图版 | 同一本书、同一版本的原书页图／图版 | 强证据；仍须核验状态 |
| E2 | 异本图版 | 同源章但不同版本、不同书的图版 | 只能标“异本”，不得写成同书图证 |
| E3 | 电子文本／OCR | PDF 文本层、OCR 文本、整理者转录 | 可定位；未回图者不得升为 E1 |
| E4b | 视频帧 | 本地抽帧、逐帧核对 | 只在帧覆盖范围内有效；不得外推全系列 |
| E4 | 字幕文本 | 视频字幕、逐字稿 | 只证明“说过”，不证明“说对”；已抽帧处低于 E4b |
| E5 | 整理者推论 | 整理者据内容所作归纳、补说、概括 | 只能作线索，不得当梁氏原文 |
| E6 | 结构计算 | 藏干、十神、五行计数等通用结构运算 | 只作结构，不作梁氏结论 |

### 1.1 不得混级

- E2 不得写成 E1。
- E4 不得写成 E1／E3。
- E5 不得写成“梁氏原话”。
- E6 不得写成“梁氏规则”。
- 同一句话有多个来源时，取最高等级并列出全部来源；不得只留最高等级而删掉较低来源。

## 2. 核验状态

| 状态 | 含义 | 能否进入确定性结论 |
|---|---|---|
| 已核 | 已回原书图版或同等强证据，逐字／逐格核对 | 可以，仍须带来源 |
| 部分核 | 已定位、已读，但未完成逐字／逐格或存在边界 | 只能条件使用 |
| 待核 | 有候选读数、有定位，但未核 | 禁止 |
| 冲突 | 两个及以上来源互相矛盾，未裁 | 禁止单取一说；并列 |
| 候选 | 来源类型为整理者归纳、旁证、低置信 | 禁止 |
| 排除 | 明确不采、空值、误读、非本表 | 禁止 |

## 3. 确定性使用级别

| 级别 | 含义 | 输出要求 |
|---|---|---|
| 允许 | 已核 + 强证据 + 无开放冲突 | 可直接引用，带 ID 与定位 |
| 条件允许 | 部分核／E2／E4／有前提 | 必须同时写出证据、前提、冲突或限制 |
| 禁止 | 待核／冲突／候选／排除 | 只能进“资料缺口”，不得进结论 |

门控规则：

1. `待核`、`冲突`、`候选`、`排除` 一律不得进入确定性结论。
2. `部分核` 只能条件使用；引用时必须带“据字幕／据异本／据文本层”等限定。
3. 有 `conflict_ids` 的规则／格值，必须并列冲突双方。
4. 冲突已有裁定的，按裁定执行并注明裁定来源；没有裁定的，不得代裁。
5. 低置信（confidence 低）不得单独支撑结论。

## 4. 冲突类型与处置

类型：

- 版本差异：不同版本、异本、修订稿。
- OCR 疑字：字形相近、系统替换、缺字。
- 理论口径不同：梁氏不同场合的说法、古今法差异。
- 资料不足：缺页、缺图、缺集、缺帧。
- 编号问题：同号互撞、跨包重叠、分母不一致。

处置：

- 并列保留：两说都留，标注来源，不合并。**给出操作口径者记「已裁定（并列保留）」**——即不二选一，但明确在什么前提下用哪一说。
- 降级：证据不足者降为候选／待核，不删除。
- 排除：明确误读、空值、非本表，记录理由。
- 占位：两说皆无证，照原样留空或并列，记「已裁定（占位）」，不补值。
- 待裁：需要总协调人或上游裁定，不得自行择一。
- 待核：已给出方向但缺外部材料（他本、原注、原书比对、四柱复核），材料到位前不得作定论。

「已裁定（并列保留）」不等于冲突消解：它只说明**引用方式已定**，双方原文仍须并列呈现。禁止把并列保留写成「已统一」。

任何处置都必须写：

- 冲突双方及来源。
- 冲突类型。
- 当前处置。
- 对最终分析的影响。
- 关闭所需材料。

## 5. 引用格式

规则引用：

```text
R123｜主题｜证据 E4／部分核／条件允许｜LX38-E20:L543-560
```

表格引用：

```text
T-X12-TH01-005｜甲日主·午月令｜值：癸｜E3／部分核／条件允许｜源定位
```

命例引用：

```text
C75（原号 K-01）｜戊辰/戊午/甲午/乙丑｜教材示范｜E1／已核｜PDF 38（书内73）
```

未决／冲突引用：

```text
U-X12-01｜TH-01 85格待核｜开放
F-X11-02｜六冲/六害 12格证据等级｜已关闭（原页回图升 E1）
```

## 6. 禁止补造

- 不得补造书名、版本、页码、集数、字幕行号、帧号。
- 不得把“通行术数知识”写成梁氏原文。
- 不得把整理者概括伪装成梁氏原话；`rule_text` 与 `normalized_statement` 必须分开。
- 不得把不同版本合并成“定本”。
- 不得为凑验收数字删除冲突、降低分母、把未核改通过。

## 7. 分母与计数

- 每个包的分母必须保留：规则 145、表 573、调候 120、六冲六害 20、视频 38/32 集等。
- 白名单、候选、排除、待核分别计数，不得只报“通过数”。
- 46 格补格不得静默并入基线编号；必须保留 `SUPP-` 原号与 U13-08。
- 12 格六冲／六害原标 E2 异本，本轮按声明源书《子平基础概要》行卯版书内10 原页回图后升 E1；引用仍须标“同源章图版”，不得写成《四角方阵》原文（F-X11-02 已关闭、U-X11-14 仍有效）。
- 升降级只认原页回图：不得因“可用”或“与通行术数一致”升 E1，也不得因“同为异本”而下压已回图的原页读数。
- TH-01 85 格为「本书未见明文」，不得因原表可读而据原表值把它们改写成 TH-01 的已核值；原表与 TH-01 是两张表。

## 8. 全局 ID 与反查

- 任何全局 ID 必须能在 `data/crosswalk.csv` 反查到源包、源文件、原始 ID、原始定位。
- 全局 ID 变更不得覆盖原 ID；原 ID 保留在 `original_id`。
- 表级 ID 与格级 ID 分开：表级用于索引，格级用于引用。
- 跨包重叠：28 集 31 行系同一 `R181` 的基线细标（`L1530-1560`）与 10 包粗块（`E28 L1467-1683`），双源并存、同集检索以细标优先、条目按 ID 计不按片段计；05 集无区间交集（U-X14-C01 已裁定）。
- 第 10 包未决分母按实载 7（`U21–U27`），不按自述 8 补号；差 1 待提交方确认（U-X14-C02 待上游裁定）。
