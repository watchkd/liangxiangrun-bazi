# 分析报告十九板块规格（交付件 B）

> 用途：给「要看为什么」的来客，或批者自查。
> 与命书的分别：命书（交付件 A，十四节）是断语体、零工程标记、给命主看的；
> 本报告是**带证据的分析件**，每一节都要能回溯到 `rules.csv` 的 rule_id 或
> `tables.csv` 的 cell_id。**两件不可混**：命书里出现 rule_id 即不合格，
> 本报告里出现无据之断亦不合格。
>
> 结构参照网友分享版《梁湘润技能包》的十九板块，但补了它没有的三样：
> ①每节挂证据；②查不出的写「查不出」，不拿通行术数补；③行动层单独立附录并声明来源。
>
> **P8 起升为 v2 版式**：十九板块不动，前后各加「卷首」与「附录」四件，判断加三档强度。
> 与网友版的逐项对照见第四节——那里写清了我们**吸收了什么、拒了什么、为什么**。

## 〇、v2 版式：一张纸上的五个区

```
卷首 A  批断流程与材料清点   材料给了什么／六步做到哪一步／本件边界
卷首 B  盘面速览             四柱盒＋速览四点＋一句话定调
①–⑲    十九板块             结构类程序填，判断类人填，每节挂证
附一    存疑与反证           逐节证据密度／强度分布／最薄三处／与通行说法差异／须补何料
附二    证据索引             全文 rule_id／cell_id 去重，逐条给来源定位与等级
```

**卷首两卡不计入十九**（`report_check` 的 B01 按圈号计数，故不被误算）。它的用处是让读者
先知道「批者手上有什么、哪一步因缺料没做」，再看断语——**把「没算」读成「没事」，是批命最常见的一种误读。**

### 判断强度三档（v2 的核心）

| 标 | 含义 | 对应的写法 | 门槛（接 `crosscheck.py`） |
|---|---|---|---|
| 〔确断〕 | 三路以上独立来源同向，且所据条目无一落在未决／冲突开放项内 | 可下肯定句 | n ≥ 门槛（3／2，视判断点）且方向一致 |
| 〔倾向〕 | 两路同向；或三路中有一路相反已权衡、或有一路所据未定 | 用「多主／宜／偏向」 | n = 门槛−1 |
| 〔存疑〕 | 仅一路来源，或所据条目 `verification_status` 非「已核」 | 只可「或可／待验」，不下结论 | n ≤ 门槛−2 |

为什么要有这一层：网友版每句都一样肯定，读者无从分辨哪句硬、哪句软。**专业批命与热闹批命的分界，
不在断语多漂亮，在知不知道哪一句是自己最没底的，并把它写出来。**
`report_check` 的 B09 要求下篇五节每节至少一处强度标（或明写「不适用」），B10 禁绝对断言。

### 一句话定调

卷首 B 末位。一句，不逾四十字，须能概括「格局＋用神＋一生大势」。
**不可含糊**（如「一生平平」），**不可许诺**（如「必富贵」）；须与 ⑤ 格局、⑦ 用神、⑲ 总纲三处不冲突——
冲突则改定调，不改三处。

### 每节的四段式（下篇尤须）

「因子表 → 判断（带强度）→ 做法（可执行）→ 反证（此判何时不成立）」。
**反证是硬要求**：不写「此判何时会错」的断语，等于不承认它会错。
网友版没有这一层，它是「全对」的报告；本包要的是「可改」的报告。

## 一、逐节规格

### ① 基本信息
**写**：性别、生年、四柱、日主、生月（节令区间）、起运、现行大运、虚岁、流年、格局一句话、定盘一句话。
**证据**：四柱、起运、大运来自 `tools/paipan.py`（E6 结构计算）；格局须挂 rule_id。
**做不到时**：真太阳时未校正的，明写「未校正（未给经度）」，不得默认校正过。

### ② 四柱排盘
**写**：四柱干支、十神、藏干、纳音、旬空；大运表（含起运年月日、交运虚岁）。
**证据**：全部 E6。**空亡须逐柱查**，并分主空（日柱旬）与次空（他柱旬）。
**做不到时**：生日距节气四十五分钟内者，`paipan.py` 会报 P09 FAIL，此时**不得出报告**，
须改用专业排盘软件复核月柱后重跑。

### ③ 五行十神
**写**：五行计数（含藏干）、十神分布、缺何行。
**证据**：E6 等权计数。**须声明「等权计数，不作旺衰加权」**——梁氏不以数字量化强弱。
**做不到时**：不得由计数直接推「身强身弱」，那要另走扶抑一路。

### ④ 刑冲合会与神煞
**写**：冲、害、合、三合、三会、刑、拱夹；神煞逐条列「查法→格值→见／不见→落哪一柱」；空亡逐柱。
**证据**：刑冲合会挂 `TB-XJ*` 系列 cell_id；神煞挂 `JS-SS-01`～`04` 的 cell_id；拱夹挂 `R-JC-01`～`07`（《子平基础概要》p154–156），写「拱得某支」而不写「明见某支」。
**做不到时**：神煞只报见／不见与落点，**不判吉凶**（两说并存，见 `R-MF-044`～`046` 与 p027 之命名说）。

### ⑤ 格局分析
**写**：月令藏干与透干、格名、顺逆、忌神与救应、结构结论（成／破／有破有救），可直接写「取某格」——P2 起格局已落算（`R-SS-002`／`R34`／`R73`／`R74`／`R-SS-012～015`）。
**证据**：格局类 rule_id（`R-*` 中 topic=格局者）；须列 ≥3 路独立来源（见 `crosscheck.py`）。
**做不到时**：来源不足门槛者，写「信号单薄，待大运验证」，不写肯定句。

### ⑥ 日主调候
**写**：调候表所取（原表列 1–5 个候选，不分主次）、原局满足度（透／藏／无）逐项比对。
**证据**：`TAB-LXR-TH-01-ORIG`（行卯版原表，120 格，119 格 E1 已核）优先；`TAB-LXR-TH-01` 为整理者复原表，须标明。
**做不到时**：**不得自行指定「正用神」**——原表未分主次，分了就是替梁氏作主。

### ⑦ 用神全景
**写**：调候／扶抑／通关／日主十干喜忌／格局需求／忌神复核，六路逐路出结论；最后汇总为「用神全景表」。
**证据**：每路挂 rule_id；六路汇总**不排名、不计票、不打分**。
**做不到时**：某路不适用（如无两神相战），明写「不适用」及理由，**不得跳过**。
**禁忌**：不写「第一用神／第二用神」——梁氏无此说。

### ⑧ 六亲专题（妻／财／子／禄／寿分列）
**写**：妻星与婚姻、财与事业、父母、子女、六亲宫位小结。
**证据**：每项 ≥3 路（婚姻）／≥2 路（子女），见 `crosscheck.py` 门槛表。
**做不到时**：寿元只判长短、不判年岁（原书明言不能只凭四柱论亡殁之年）。

### ⑨ 大运走势
**写**：每步大运的干支、十神、与原局的刑冲合会、五法（十干败亡／墓库／空亡／接角／冲提）逐项。
**证据**：`R-SZ-025` 等；墓库运**只限辰戌丑未月生人**，非四库月直接判不适用。
**做不到时**：「夹」之取法原文未给，本包不判。

### ⑩ 流年
**写**：当年流年干支、与大运／原局的关系、应期三段（运定十年→年定年份→月定月份）。
**证据**：流年类 rule_id。
**做不到时**：**流月无材料**，只到结构不到应事，明写。

### ⑪ 人生建议
**写**：一条主线、三到四件要做对的事、**全局配合声明**（列明哪些结论来自哪几路独立来源、哪一处存在矛盾及如何权衡）。
**证据**：全局配合声明是硬要求，不可省。
**做不到时**：不确定者写「待大运进一步明确」。

### ⑫–⑯ 学业／事业／财富／人际／健康 说明书
**写**：每项按「职业基因／财富模式／体质倾向」三到四因子摊开，再给可执行建议。
**证据**：因子表同 `crosscheck.py`；健康措辞限「偏热／偏寒／偏燥／偏湿」「须注意」，**不做疾病诊断**。
**做不到时**：健康无显明症兆者不批（原书：「有显明之症兆，才批出断句」）。

### ⑰ 年度行动指南
**写**：未来三到五年逐年一句，标出与流年刑冲合会相关的关口。
**证据**：只作结构提示，不排月。
**做不到时**：明写「逐年细批须另立流年书」。

### ⑱ 风险与禁忌
**写**：四项基本风险（天罗地网／墓库运／冲提运／拱合冲边）逐项检查；再列须避之事。
**证据**：每条挂 rule_id；**不得写成「必然发生」**。
**做不到时**：原局无此结构者写「不犯」，不硬凑。

### ⑲ 总纲
**写**：一段总结，回到「这个人这一生大体怎么走」。
**证据**：不新增判断，只收束前十八节。
**做不到时**：结尾须有「切忌以包准自居」一类分寸语（原书语：能有个七成应验，就算合理合宜）。

## 四、怎么用（生成 → 填 → 验收，三步）

规格写成文档之后，仍旧是「看着办」。P4 起把这三步落成工具：

```bash
# 第 1 步：出骨架。结构类板块自动填，判断类板块留「〔待批〕」
python tools/report_gen.py 癸巳 戊午 丙午 壬辰 --gender 男 \
    --dayun 己未,庚申,辛酉,壬戌 --birth-year 1953 --start-age 8 \
    --liunian 2026,2027 --out 报告.md

# 第 2 步：填。把每处「〔待批〕」换成断语；条文池已按主题过滤好，用不用由批者定
#        （生成器不写断语——断语是判断，工具不替人做）

# 第 3 步：验收 + 出索引
python tools/report_gen.py --audit 报告.md --write   # 重算卷末「存疑与反证」
python tools/report_gen.py --index 报告.md --write   # 重算卷末「证据索引」
python tools/report_gen.py --from-md 报告.md --out 报告.html   # 出 v2 版式（左目录＋强度角标）
python tools/report_check.py 报告.md --type report
```

**填完之后的三步**（顺序不可倒）：`--audit` 算强度分布 → `--index` 收证据 → `report_check` 验收。
先出 HTML 再补审计，则 HTML 里还是占位——**顺序错了，成品就是半成品。**

**哪些自动填、哪些必须人填**：

| 板块 | 谁填 | 说明 |
|---|---|---|
| ① 基本信息 ② 四柱排盘 ③ 五行十神 | 程序 | E6 结构；③ 已声明「等权计数不作旺衰加权」 |
| ④ 刑冲合会与神煞 | 程序 | 四表实查逐行出「查法→格值→见否→落柱→表值」；只报见否，不判吉凶 |
| ⑤ 格局 ⑥ 调候 ⑦ 用神 | 程序 | ⑤ 出格名／顺逆／忌神救应表；⑥ 逐字判「透／藏／无」；⑦ 五路并列不计票 |
| ⑨ 大运 ⑩ 流年 ⑱ 风险 | 程序 | ⑱ 四项结构实算＋条号回查；「不适用」照写，不硬凑 |
| ⑧ 六亲 ⑪ 建议 ⑫–⑯ 说明书 ⑰ 年度 ⑲ 总纲 | **人** | 留「〔待批〕」＋条文池；门槛、措辞、分寸语写在待批清单里 |

**两条纪律已写进工具**：

1. **骨架不许冒充交付件。** `report_check.py` 的 B06 专查「〔待批〕」；生成器刚出的稿子必然 FAIL。这是设计意图——能过的那份，一定有人真填过。
2. **索引只收真编号。** `--index` 只收 `rules.csv`／`tables.csv` 里存在的条目；`TB-XJ*` 一类通配前缀与表号不计入，另行报数，免得索引里混进「查不出」噪音。

范本：`_命书/报告_癸巳戊午丙午壬辰.md`（C01 任铁樵造）——**v2 版式**：卷首两卡＋十九板块＋附一附二，
21.8k 字、78 条证据、`report_check` **12 通过／0 警告／0 失败**；同目录 `.html` 为同稿版式件。读它比读本规格快。

## 五、与网友版逐项对照（P8）

网友版指 `网友分享版/梁湘润技能包.zip`（四文件，SKILL 57 KB＋理论 69 KB＋模板 27 KB）。它的长处是**结构与可读性**，
短处是**无据可查、无闸可拦**。本包的做法是：形制取之，筋骨另立。

### 吸收五项

| 项 | 网友版做法 | 本包做法 |
|---|---|---|
| 十九板块 | 上篇「梁师批命」十节＋下篇「人生说明书」九节 | 全数沿用编号与题名，不改 |
| 版式 | 暖米＋金、Noto Serif、卡片、Hero 四柱盒 | 改为纸墨系统（宣纸底／朱批红／出处蓝），左目录＋右纸页；四柱盒保留 |
| 排盘验证清单 | Hero 下方手写 ✅ 清单 | 改为程序实算填充（`paipan.py` E6），并升级为卷首「材料清点」 |
| 用神六路 | 六步法、不计票不排名 | 同（本包 ⑦ 已如此），另标「五路落算／两路须人工」 |
| 多因子交叉 | 十七个判断场景 × 最少信号数 | 沿用其场景表，落成 `crosscheck.py` 门槛表，并把门槛接进判断强度三档 |

### 拒收三项

| 项 | 网友版做法 | 本包拒收理由 |
|---|---|---|
| 星级评级 | 五星、「评分 95」 | 不可证，最易「以包准自居」。改三档「宜／平／避」 |
| 具体城市／楼层／配饰色号 | 「学校/地区(具体城市)」「置业方位(楼层)」 | 梁氏书无此说。移入附录并声明「通行引申，非梁氏原文」 |
| 华盖「仅年支起算」 | 定则式断言 | 《子平基础概要》神煞例表（四）表头明写「日柱地支」，以书为准 |

### 补其不足三项

| 不足 | 后果 | 本包补法 |
|---|---|---|
| 无证据链 | 断语不可回溯，错了无处定位 | 每节挂 rule_id／cell_id；附二逐条给书名·页／节与证据等级 |
| 无「查不出」 | 每项都要填满，必然编造 | 允许「查不出／不适用／待人工／原文待核」；B02 认这四种写法 |
| 每句一样肯定 | 读者无从分辨硬软 | 判断强度三档＋附一强度分布表＋「最薄三处」自陈 |

### 一处刻意不同：卷首与附一

网友版把「排盘验证清单」做成一句手写 ✅；本包把它扩成两份**自动算出来**的东西：
卷首「材料清点」（缺料→影响）与附一「证据强度分布」（逐节证据数、强度分布、最薄三处）。
这两份都不是断言，是**自陈**——把「我知道自己哪里薄」写在前面，比把「我很专业」写在前面有用。

附一「最薄三处」的**取项规则**（`--audit` 实算，人工不得改）：

1. 只从**判断节**（有强度标者）中选；标「结构」的节（四柱、表值、见否）只报值不作断，
   无「薄」可言——排盘不需几十条规则背书，证据少属正常，不参赛。
2. **总纲（⑲）不参赛**：收束节的证据挂在前节，本节 0 条不是薄，是必然。
3. 排序按「证据条数 ÷ 判断数」低者优先，存疑多者次之；**不足三处须从余下顺位补足**。
   ——标题写「三处」而正文列两处，是报告自己戳穿自己，比不写这一节更伤。
