# 六书台账（corpus 索引）

这一页回答一个问题：**某条断语要回查时，去哪本书、翻哪一页。**

包内规则 1,164 条，凡有 `source_locator` 的，都能按本页找到底本页码。
定位方式统一为 `书号:p页码`，例如 `XC:p028`＝《四角方阵刑冲合会透解》第 28 页。

> **先说清楚包里有什么。** 十二本书的**逐页全文不入包**。包内是一份「引文核验库」
> （`data/quotes_verify.txt`）：只收被规则引用之处及其邻近上下文，未被引用的页一字不留；
> 另有一份页级索引（`data/corpus_digest.csv`），只给页号不给正文。
> 所以本页的作用是**指路**——告诉你这句出自哪本书哪一页，请翻原书。原书全文由
> `_dev/distill_corpus.py` 从底本机械抽取而成，抽取过程可复现、未改一字。

### 用法

```bash
python tools/corpus_search.py 四角            # 全库检索
python tools/corpus_search.py 天乙 --book XC   # 限一本
python tools/corpus_search.py "三刑.*自刑" --re --ctx 2
python tools/corpus_search.py --list          # 列出可检索／不可检索书目
```

输出形如 `XC:p028  《四角方阵刑冲合会透解》 …寅申亥亥…`，`XC:p028` 可直接抄进规则的 `source_locator`。

### 三条使用纪律

1. **DC 只作参照，不得单独作断。** OCR 繁体稿错字率高，据其立论者 `confidence` 一律记低。
2. **XC 的 p164–226 是图版主表，无文字层。** 那是「二元全流刑冲 3600 组」正表，
   本包只以规则骨架（二十组名目＋查表法，R-XC-053～056）入条，**具体组格查不了**。
   需要某一组的确切吉凶时，只能回 PDF 看图，不能拿骨架条硬套。
3. **页锚＝PDF 页序，不等于书上印刷页码。** 引用书内页码时要另行换算，本包 locator 一律用 PDF 页序。

## 二、在架未数字化（三本）

| 书号 | 书 | 页数 | 现状 | 为什么没全文 |
|---|---|---|---|---|
| SP | 《神煞探原》 | 166 | 目录＋神煞表页已转录（15 页） | 扫描件无文字层，本机无 OCR 引擎 |
| ML | 《命略本纪》上／下册 | 各 185 | 上册目录＋核心章节已转录（18 页） | 同上 |
| ZG | 《宰公要诀》 | 124 | 目录＋六十日时吉凶表已转录（17 页） | 同上 |

转录件在 `references/corpus/`：`sp_toc_raw.md`、`ml_toc_raw.md`、`zg_toc_raw.md`，
逐页 `===== pNNN =====`，照录原文、不校勘、辨认不出记 □。
章节页码表在 `data/sp_toc.csv`、`data/ml_toc.csv`、`data/zg_toc.csv`。

**这三本能做什么**：
- 按目录查「某章在第几页」，再回 PDF 看图；
- 查已转录页上的具体内容（如宰公要诀「六十日时吉凶」、神煞探原「月建十二神」「歲幹合表」）；
- 不能做：全书逐条检索、按词条穷举。

**这三本不能做什么**：不得声称「《神煞探原》已入库」或「全书已核」。
凡结论须依赖这三本而转录页未覆盖者，一律记入 `UNRESOLVED_REGISTER`，不得凭印象补。

## 三、逐页偏移（转录件专用）

三本的印刷页码与 PDF 页序各有偏移，回查时按此换算：

- **ZG 宰公要诀**：`PDF 页 = floor(印刷页 ÷ 2) + 1`（双页拼版，右页偶数在前）。
  p001 为封面独页，不参与拼版。
- **SP 神煞探原**：前段 `印刷页 = 2×PDF页 − 2／−1`；**p082 起改为 −4／−3**。
  原因是 p080 与 p081 为同一跨页的重复扫描，多占一页。目录所标与正文另有 2 页自差。
- **ML 命略本纪**：目录自成一编号（1–4），正文另起；册内偏移见 `data/ml_toc.csv` 的 `pdf_page` 列。

## 四、缺口与不实之处（照实写）

- 三本扫描件**未全文数字化**，因为本机无 OCR 引擎、pip 源不可用，装不上 PaddleOCR／Tesseract。
  要补，须先解决 OCR 环境，再按 `_dev/corpus_build.py` 的同一格式重建。
- 《命学大辞渊》虽有 OCR，但**辞典体例未做词条切分**，只能全文检索，不能按词条跳转。
- 《四角方阵》p164–226 的 3600 组主表**未建 table 条目**，`related_table_ids` 因此留空。
- 《子平基础概要》p152–153 等表格页，转录稿单元格次序与 PDF 抽取次序不同，本批引文未取那几页。

## 五、维护

新增一本书，按三步走，缺一步都不算入库：

1. `_dev/corpus_build.py` 的 `BOOKS` 表登记（书号、前缀、源文件、页标记正则、输出名）；
2. 跑 `--build` 生成 `data/quotes_verify.txt` 的对应段，页锚必须连续无缺口；
3. 在 `tools/corpus_search.py` 的 `BOOKS` 字典加一行，`data/source_manifest.csv` 登记 `SRC-LXTEXT-<书号>`。

`tools/validate.py` 的 R18 会核对本页所列书号、全文文件、页数三者是否与实际一致；
R19 会实跑检索器确认可用。改了书不改这三处，校验必响。
