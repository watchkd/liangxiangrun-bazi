# 分析流程与检索配方

本文件是 `SKILL.md` 的执行细则。所有步骤都以“有来源才说、无来源不说”为前提。

## 0. 输入校验

1. 四柱顺序固定为年、月、日、时。
2. 每柱必须是六十甲子中的合法干支：
   - 天干：甲乙丙丁戊己庚辛壬癸
   - 地支：子丑寅卯辰巳午未申酉戌亥
   - 干支阴阳须同（甲子可，甲丑不可）。
3. 缺柱、错字、性别缺失：先说明，不补、不猜、不排盘。
4. 用户只给生日：拒绝自行换算，要求其先提供四柱或排盘结果。

## 1. 结构展开（E6，非梁氏判断）

展开内容：

- 年／月／日／时四柱。
- 每支藏干（本气、中气、余气）。
- 以日干为基准的十神：比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印。
- 五行计数：天干＋藏干。
- 十神出现次数：不含日干本身。

必须注明：

> 藏干与十神为结构展开（E6），不是梁氏判断本身。梁氏对支藏强弱的取法见 R64；不得以通用藏干表替代其取用结论。

## 2. 按梁氏次序分析

梁氏资料里有两种次序，须并置说明：

- T06-01～03（三步）：五行全不全 → 刑冲合会 → 定格局。
- T21-01～05（五步）：五行全不全 → 最忌冲刑 → 格局顺逆 → 调候反看 → 流年架势。

执行时按五步走，但每一步标注对应 T06／T21 格值。

### 2.1 五行全不全

- 查天干与支藏天干。
- 只作结构统计，不直接断吉凶。
- 女命“最怕缺官杀”、男命“最怕缺财”见 T21-01；性别未定时不代入。
- 相关规则：R11（缺五行之断法）、R136（六亲/缺五行：男怕缺财、女怕缺官杀）。

### 2.3 定格局

自 P2 起**落算三层**，不再只说候选（`tools/analyze.py` 第七节即此三层）：

1. **取格**：月令藏干按本气→中气→余气查透干；本气透则取本气，本气不透而中气／余气透则取透者并标“格根不正之位”；全不透则依 R-SS-002 取本气。格名由十神定，比肩在禄位作建禄格、阳干劫财在刃位作羊刃格（R148／R-XJ-02）。
2. **顺逆**：R74／R-SS-017——官印食财顺用，煞伤劫刃逆用。
3. **结构成败**：顺用查忌神（R-SS-014）与救应（R-SS-013／019／020／021）；逆用查反克之神（R-SS-022）。忌神按落点分「透／本气＝有力」与「中余气＝力薄」，力薄不计为破。

**未落算、须人工对条文**：相神（R-SS-033／034）、有情有力（R-SS-028～030）、十四制式（R-SS-036～041）、双格轻重（R-SS-024～026）。**不得由程序代判吉凶与富贵层次。**

冲突提示：

- F05：月令格局的优先权，古法与梁氏今法未合并——影响的是“格局在取用次序中的权重”，不影响“格名怎么取”。
- F06：日主喜忌与调候孰先未裁。

### 2.5 流年／大运

- 用户未提供大运、流年时，不分析。**不得自行起运、排大运**；流年可给公历年或干支，`analyze.py` 只做干支换算，不校立春（跨春节须以 `paipan.py` 复核）。
- 大运：`analyze.py --dayun` 落五法（十干败亡／墓库／空亡／接角／冲提）＋冲柱分级＋拱；`mingshu.py` 另出调候向背与全流表。
- 流年：`analyze.py --liunian` 落九法——架势（R97）、双冲旬内旬外（R122）、双六合在运在年（R126）、三合三会（R164）、冲运与冲柱之别（R209）、临官年（R220）、岁运并临（R-SZ-041）、运中四组（R-MF-017）、冲提年诸忌（R-SZ-028）；`--liuyue` 附流月伏吟／反吟／双合（R118）。
- **两档纪律**：架势／双冲／三合三会／双六合／冲运／岁运并临／运中四组／冲提年／临官年＝「主命中」，可断；刑／单冲／单合／伏吟／反吟＝「只记结构」，不作断。R135：流年非每年有事，不得逐年充数。
- 流年吉凶之轻重与应期先后，程序不排；流月只对运（R118），不对四柱与流年；调候格局喜忌不用于流月（R-X13-068）。

### 2.6 岁运动态层批法（强制八条，2026-11 外部复核后固化）

背景：一次真实盘复核（甲子乙亥庚戌癸未）量出——**原局层几乎无错，错漏集中在岁运动态层**。
静态层有格值表与校验器盯着，动态层靠下面八条守住，逐条强制、缺一即返工：

1. **批运固定四问**：调候（字须挂十神，丁是正官、丙是七杀，两样口气）→ 扶抑 → 格局 →
   刑冲合会破穿。每问落一行结论，四问同向直断；两两相反写「得中带失／凶中带财」复合断。
   **禁单键否决**——某一步运「比肩帮身」被调候不吉盖掉，就是这一条没跑（真实案例：庚辰运）。
2. **三层关系矩阵跑全**才许写「不相关」类断语：原局×原局、运×原局、运×流年。
   原局两支作势、运或流年补第三支即成局成刑。真实硬错：「丑与月支亥无涉」——
   原局亥子＋运丑正成北方三会；同轮漏掉丑戌未三刑全备、子卯刑。
3. **硬法先补适用条件再落笔**：「禄入墓库运主凶」限**日主自身之禄或用神**入墓，
   病神入墓反主去病；「十干败亡」限四柱地支不带临官帝旺；「魁罡忌冲刑」是通则、
   辰戌冲另有**冲开官库**一面。引任何成法，补一行适用条件，两面读再裁决。
4. **神煞岁运填实点名**：命带羊刃，帝旺之年即是羊刃值岁；罗网、空亡等在何运何年
   凑齐条件，逐一点名。不得拿「帝旺」「临官」的说法把填实之年躲过去。
5. **空亡须说出空**：落空之支逢冲、逢合、出旬填实之年，其事发力。只写「落空打对折」
   不写出空，等于把应验窗口藏起来。
6. **六亲断语回填应期或标待验**：父母、兄弟、婚姻各断，能推的给出运年窗口
   （如财坏印之母灾在何运何年），推不出的标「待验」，与来客对实事后再校。
7. **流年表文对应**：流年举要表里出现的每个年份，正文须有对应批语；只给结构标签
   不给正文，等于让来客自己猜。凑不齐条件的签，**降一等并明言所欠之字**，不代裁。
8. **禁否定断语与未定次序**：批词不得出现「无涉／不相干／互不相犯」「并列不分正副」
   ——前者是三层矩阵没跑全的信号，后者等于调候没定次序。R28 守此两条。

## 4. 规则检索

`tools/analyze.py` 的检索是“线索”，不是裁决。执行者须复核：

1. 规则 `scope` 是否匹配性别。
2. `conditions` 是否满足；不满足时只能作“相关规则”列出，不能当结论。
3. `deterministic_use` 是否为 `允许` 或 `条件允许`。
4. `verification_status` 是否为 `已核` 或 `部分核`。
5. `conflict_ids` 是否触发；触发时并列冲突。

排序不是置信度。score 高只说明关键词命中多，不代表规则更适用。

## 5. 命例对照

- 只对照四柱完全相同的命例。
- 不完整命例（3/4 柱、2/4 柱、非四柱）不得当完整四柱案例。
- 命例只作说明与有限对照；不得因结果相似提升规则置信度。
- K-01～K-03 为教材取用示范，无现实事件验证；K-02／K-03 另有五虎遁矛盾（F-X12-06／07）。
